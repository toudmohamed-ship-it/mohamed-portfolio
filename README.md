# mohamedtoudghi.com

Portfolio of Mohamed Toudghi, SEO and growth specialist. Next.js 16 (App Router), Tailwind CSS 4 and next-intl, deployed on Vercel from `main`.

- English at `/`, French at `/fr`, Arabic at `/ar`. Copy lives in `messages/*.json`.
- Rules for content, design, SEO and performance: `CLAUDE.md`.
- Plans: `docs/growth-plan.md` and `docs/semantic-seo-audit.md`.

## Run it

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

Work on a branch. Merging into `main` publishes the site.
